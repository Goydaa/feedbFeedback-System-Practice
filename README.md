# Система обратной связи (Feedback System)

Информационная система для сбора и обработки отзывов пользователей. Проект подготовлен как сопровождаемая программная система в рамках учебной практики УП.03 «Сопровождение и обслуживание программного обеспечения».

---

## 🛠 Стек технологий
- **Backend:** `Python 3.10+` & `Flask`
- **ORM:** `SQLAlchemy`
- **Database:** `SQLite`
- **Containerization:** `Docker` & `Docker Compose`
- **CI/CD:** `GitHub Actions`
- **Deployment:** `Gunicorn`

---

## 📋 Документация и отчетность
Проект организован как сопровождаемая система. Каждому этапу разработки соответствует отдельный отчет:
* `INSTALL.md` — Инструкция по инсталляции и контейнеризации.
* `DEPLOYMENT.md` — Руководство по развертыванию.
* `TESTING.md` — Результаты автоматизированного тестирования.
* `SECURITY.md` — Отчет по настройкам безопасности.

---

## ⚙️ Инженерные решения
- **Контейнеризация:** Использование `Docker` обеспечивает идентичность окружения на любых машинах.
- **Автоматизация (CI/CD):** Настроен `GitHub Actions` для автоматического тестирования при каждом push'е.
- **Безопасность:** Реализован `.gitignore` для исключения чувствительных данных (`.env`, `instance/`).
- **Качество кода:** Реализованы Unit-тесты (`test_app.py`) для проверки основных маршрутов приложения.

---

## 🚀 Основные возможности
### 👤 Для пользователя:
- Форма обратной связи.
- Валидация входных данных.

### 🔐 Для администратора:
- Панель управления с авторизацией (`Flask-Login`).
- Цветовая индикация категорий обращений.

## 💻 Инструкция по запуску

Для быстрого развертывания используется Docker:

1. **Клонируйте репозиторий:**
   
   git clone <ссылка-на-ваш-репозиторий>
   cd feedback-main



2. **Запуск через Docker:**

docker-compose up --build




3. **Доступ:**
После запуска сервис будет доступен по адресу: `http://localhost:5000`

### 🧪 Автотесты:

Для проверки целостности системы используйте команду:


python test_app.py
