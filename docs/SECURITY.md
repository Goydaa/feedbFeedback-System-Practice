# Отчет по безопасности

## Меры защиты
1. **Исключение секретных данных:**
   Создан файл `.gitignore`, который блокирует попадание в репозиторий:
   - Файлов с переменными окружения (`.env`) с паролями и ключами.
   - Локальной базы данных (`instance/`).
   - Кэшированных файлов Python (`__pycache__/`).

2. **Защита доступа:**
   В проекте используется базовое ограничение доступа для панели администратора.

## Проверка
Файлы `.env` и папка `instance/` не отслеживаются Git, что предотвращает утечку данных при публикации на удаленные ресурсы.
