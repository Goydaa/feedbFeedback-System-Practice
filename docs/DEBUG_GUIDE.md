# Отчет по отладке и условной компиляции

## 1. Системные компоненты для проверки
На данном этапе проверялись следующие критические компоненты:
- **Модуль валидации формы:** обработка входящих POST-запросов.
- **Модуль авторизации (Flask-Login):** контроль доступа к панели управления.

## 2. Инструменты и методы отладки
- **Логирование:** Использование встроенного логирования Flask для отслеживания маршрутов и обработки данных.
- **Инструменты разработчика (F12):** Анализ сетевых запросов при отправке отзывов.
- **Режимы сборки (Условная конфигурация):** Использование переменных окружения (.env):
  - `DEBUG=True`: Активирует режим разработки (подробные трейсы ошибок).
  - `DEBUG=False`: Активирует режим Production (скрывает технические детали, использует Gunicorn).

## 3. Таблица ошибок и соответствие спецификации
| Компонент | Ожидаемое поведение (по ТЗ) | Фактическое поведение | Ошибка | Статус |
| :--- | :--- | :--- | :--- | :--- |
| Авторизация | Доступ только администратору | Доступ был открыт всем | Неверный декоратор | Исправлено |
| Форма | Валидация полей | Пустые данные уходили в БД | Отсутствие `required` | Исправлено |

## 4. Выводы
В ходе отладки системные компоненты были приведены в соответствие со спецификацией. Использование переменных окружения позволило гибко управлять режимами сборки без изменения исходного кода. Система стабильна и готова к промышленной эксплуатации.
