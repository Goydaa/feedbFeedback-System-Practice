# Входной аудит проекта Feedback System

## 1. Краткое описание проекта
Информационная система для сбора и обработки отзывов пользователей. Цель проекта — автоматизировать прием обращений, обеспечить их категоризацию и предоставить администратору удобный инструмент управления заявками. 
**Целевая аудитория:** пользователи сайта (отправители) и администратор (модератор).

## 2. Источники информации
Для сбора требований были определены следующие источники:
- **Пользователи:** для анализа сценариев использования формы (ожидания по простоте и скорости отправки).
- **Администратор:** для уточнения требований к системе приоритетов (категории, цветовая индикация).

## 3. Выбранные методы получения требований
- **Анализ аналогов:** Изучение существующих форм обратной связи для выбора оптимального состава полей (Имя, Email, Категория, Текст). Это позволяет избежать типичных ошибок проектирования.
- **Прототипирование:** Создание черновых макетов интерфейса в HTML/Bootstrap для наглядной проверки сценариев использования и уточнения требований к данным.

## 4. Рабочие материалы
### Пример вопросов для интервью (моделирование):
1. Какие категории обращений являются наиболее частыми и требуют приоритетной обработки?
2. Какие данные пользователя критически необходимы для обратной связи (достаточно ли Email или нужен телефон)?
3. Нужна ли пользователю система уведомлений о том, что его отзыв принят?

## 5. Результаты и выводы
В ходе этапа были уточнены требования к БД (необходима таблица `categories` для классификации) и требования к безопасности (нужна авторизация для доступа к панели администратора). Проект готов к фазе детального проектирования и реализации.

## 6. Технический стек
- Python 3.10+
- Flask 2.x
- SQLAlchemy (SQLite)
- Gunicorn (для деплоя)
- CI/CD: GitHub Actions (для автоматизации проверок)
