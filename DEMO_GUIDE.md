# Руководство пользователя (Демо-стенд)

## Как пользоваться системой
1. **Главная страница:** Перейдите по адресу `http://localhost:5000`.
2. **Отправка отзыва:** - Введите имя и email.
   - Выберите категорию обращения.
   - Напишите текст отзыва и нажмите «Отправить».
3. **Панель администратора:**
   - Перейдите по ссылке `/login`.
   - Введите логин: `admin`, пароль: `admin`.
   - В панели управления вы увидите список отзывов с цветовой индикацией приоритета.
