# Отчет по отладке и условной компиляции

## 1. Компоненты отладки
- Модуль обработки данных (валидация формы).
- Модуль авторизации (проверка сессий).

## 2. Методы отладки
Используются флаги окружения (переменные в `.env`) для переключения режимов (DEBUG=True/False) и логирование Gunicorn при запуске в Docker.

| :--- | :--- | :--- | :--- | :--- |
| Авторизация | Доступ только после логина | Доступ был открыт всем | Неверный декоратор | Исправлено |
| Форма | Валидация полей | Пустые данные уходили в БД | Отсутствие `required` | Исправлено |

## 4. Вывод
Системные компоненты полностью соответствуют требованиям спецификации после исправления выявленных недочетов.

## 5. Инструменты отладки
- **Логирование:** Использование встроенного логирования Flask для отслеживания POST-запросов.
- **Инструменты разработчика браузера (F12):** Анализ сетевых запросов при отправке формы.
- **Режимы окружения:** Использование переменной `DEBUG` в `.env`. 
  - `DEBUG=True`: вывод подробных стеков ошибок для разработчика.
  - `DEBUG=False`: скрытие деталей реализации для конечного пользователя (безопасный режим).

Проверка системных компонентов (валидатор формы, система авторизации) показала полное соответствие заявленным требованиям (см. таблицу в п. 3).
